Desde la raíz de este checkout, con el contenedor correcto encendido:

python verificacion_postgresql/verificar_postgresql.py --repo . --container data_warehouse_cdmx --output resultado_postgresql.json

Sustituye el nombre del contenedor si es diferente. --database y --user permiten
otra base/rol. Este modo necesita Python 3.10+ y Docker; usa psql del contenedor,
sin dependencias Python externas. Para PostgreSQL fuera de Docker, instala los
requisitos de verificacion_postgresql/requirements.txt y configura DW_DSN en el
entorno de esta PC. Prefiere DW_DSN a poner una contraseña en un comando.
Lee verificacion_postgresql/LEEME.txt para detalles.

Todas las consultas corren en una transacción REPEATABLE READ, READ ONLY y se
revierte al terminar. El programa no crea datos ni reexporta archivos. Comprueba
que termine con código 0 y status=pass/passed=true; sólo entonces declara cerradas
las tres comprobaciones. Código 1 significa diferencias; código 2 significa que
no se completó la verificación. No equivalen a aprobado.

Si hay diferencias, identifica consulta, campo, grano, orden, tipo, nulos, filtros
